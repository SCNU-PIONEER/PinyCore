## 滤波器代码说明
### FIR滤波器
```c++
template <uint8_t RANK> class FIR
```
此滤波器需与matlab 或python等滤波器参数生成工具搭配使用

### 低阶IIR滤波器(这里介绍低通，带通的类似)
IIR滤波器设计方法有手搓滤波器，直接选择滤波器类型传入截止频率即可。
高阶手搓时间太长且手搓我只会搓一阶节，并且高阶一阶节十分不稳定，因此高阶只能使用matlab等工具生成二阶节系数

#### IIR基类
```c++
template <uint8_t RANK> class LPFIIR
```
由于巴特沃斯，切比雪夫等滤波器都为IIR滤波器，因此IIR滤波器为基类，其他滤波器继承IIR

主要变量
```c++
template <uint8_t RANK> struct LPFIIRCoeffs_s {
    float NUM[RANK + 1]{};
    float DEN[RANK + 1]{};
    float x[RANK]{};
    float y[RANK]{};
    float sampleRate_ = 0.f;
    float cutoffFreq_ = 0.f;
    struct NormParam_s {
        float a[RANK + 1]{};
        float epsilon_ = 0.f;
    } normParam_;
};
```

#### 继承类
```c++
class LPFIIR2 : public LPFIIR<2>;
class LPFIIR3 : public LPFIIR<3>;
```
巴特沃斯的归一化系数和切比雪夫的归一化系数不同，因此在构造函数需传入FilterType_e
并且切比雪夫在设计滤波器时所需求的纹波不同时归一化系数也不同，因此需要传入Ripple_e，选择不同的纹波

阶数不同时对应的归一化参数不同    
```c++
const std::unordered_map<Ripple_e, LPFIIRCoeffs_s<2>::NormParam_s> IIR2PARAMS = {
        { Ripple_e::NONE, { .a = { 1.f, std::numbers::sqrt2, 1.f }, .epsilon_ = 0.f } },
        { Ripple_e::DB0_5, { .a = { 1.5162026f, 1.4256245f, 1.f }, .epsilon_ = 0.3493114f } },
        { Ripple_e::DB1, { .a = { 1.1025103f, 1.0977343f, 1.f }, .epsilon_ = 0.5088471f } },
        { Ripple_e::DB2, { .a = { 0.8230603f, 0.8038164f, 1.f }, .epsilon_ = 0.7647831f } },
        { Ripple_e::DB3, { .a = { 0.7079478f, 0.6448996f, 1.f }, .epsilon_ = 0.9976283f } }
    };
Ripple_e::NONE对应的就是巴特沃斯滤波器
```

## 滤波器特性说明
说明滤波器的特性，可以从响应曲线，幅频特性，相频特性，稳定性，等等方面进行说明
### FIR滤波器
FIR滤波器的核心特征是系统的单位脉冲响应在有限时间内完全衰减为零。从实现结构上看，它本质是一个移动平均模型，
输出仅依赖于当前和过去的输入信号值，对输入序列进行加权和。这种没有输出反馈的结构，在数学上表现为一个卷积和。

#### 稳定性
FIR滤波器具有先天性的绝对稳定优势。由于其系统函数的所有极点都位于Z平面的原点(全是分子，分母不就为1咯，其实可以说没有极点)，
因此不存在极点位于单位圆外而导致不稳定的情况。这一特性使得FIR滤波器在设计时**几乎无需担忧稳定性问题**。
因此FIR滤波器在设计中才能出现各种灵活的设计，去filterDesigner中看看FIR一栏你就能发现有11种设计方法，而窗函数法里又有n种窗函数，甚至还可以用户自定义
所以理论上来说你随便写些数字上去，这个滤波器都可能是稳定的可以用来滤波的，只是你不知道用了什么方法设计的，他的滤波参数是多少罢了

#### 线性相位与延迟
FIR滤波器可以轻松实现严格的线性相位，这是其最突出的优点之一。线性相位意味着信号中所有频率成分通过滤波器后，在时间上经历相同的延迟，
从而避免波形失真。当然这并不是说所有的FIR滤波器都是线性相位的，为了实现线性相位，FIR滤波器的系数必须是某种对称或反对称的结构。
大部分的设计方法都是对称或者反对称以使线性相位，但是也有非对称的，比如最小P范数，这就是非线性相位的，但是这种滤波器一般不会用

#### 幅值响应与加窗
FIR滤波器理想的响应在频域是矩形窗，对应到时域是无限长的sinc函数。但是这是不可能实现的，一是其为无限长，二是因为其为非因果信号。
因此通常会在FIR滤波器的系数上乘以一个窗函数，这就是加窗法，将sinc函数截断，从而实现有限长度的FIR滤波器。

矩形窗是最简单的窗函数，但是其在频域上为sinc函数，导致频谱泄露
##### 频谱泄露
在对一个有限长度的离散时间信号进行傅里叶分析（如进行DFT或FFT）时，由于信号的有限长度截断，导致其离散频谱（频率成分）不是集中在其真实的频率分量上，
而是“泄漏”或“扩散”到整个频率轴上的其他频点，形成虚假的频率成分和幅值分布。(还有什么吉布斯效应，感兴趣可以了解，我就没去深入看了)，即在频域上产生旁瓣。
因此会有十分显著的纹波(FIR基本为阻带波纹)，且随着阶数的增加，纹波会越来越严重。

##### 非矩形窗
即用一个两端平滑渐变为零的窗函数，如汉明窗、汉宁窗等。加非矩形窗后频谱旁瓣更低，从而极大地抑制了波纹，减小频谱泄露，但主瓣更宽，过渡带更宽
加窗法的过渡带与旁瓣是不可兼得的，没有办法同时减小旁瓣和过渡带，因此需要根据需求选择合适的窗函数，采样频率内没有旁瓣说明过渡带极长
常用非矩形窗：
**汉宁窗**：通用性最好，旁瓣衰减快，适用于大多数频谱分析，过渡带窄
**海明窗**：主瓣稍宽于汉宁窗，但旁瓣抑制也较好，过渡带稍宽于汉宁窗
**布拉克曼窗**：旁瓣衰减最快，但主瓣最宽，过渡带最宽

**幅值响应**：所以FIR滤波器的幅值响应主要看的就是旁瓣和过渡带

加窗只是最简单的一种方法，还有其他方法，比如最小P范数，最小二乘法，最大熵等，这些方法在filterDesigner中都有，但是这些方法太复杂了我就没怎么看过

### IIR滤波器
IIR滤波器的核心特征是系统的单位脉冲响应在理论上是无限长的，会逐渐衰减但永不绝对为零。从实现结构上看，它通常基于递归差分方程，
输出不仅依赖于当前和过去的输入，还依赖于过去的输出。这种带有反馈回路的结构，在数学上对应于一个有理传递函数。

#### 不同逼近方法
理想滤波器要求幅频特性 A(ω) 在通带内为一常数，在阻带内为零，没有过渡带，还要求群延时函数在通带内为一常量。实践中往往选择适当逼近方法，实现对理想滤波器的最佳逼近。
比较常用的逼近方法有：
巴特沃斯逼近：基本原则是使幅频特性在通带内最为平坦，并且单调变化。
切比雪夫逼近：基本原则是允许通带内有一定的波动量 ΔKp​，但其幅频特性更接近矩形。
贝塞尔逼近：主要侧重于相频特性，基本原则是使通带内相频特性线性度最高，即群延时为常量，从而使相频特性引起的相位失真最小。
           因此音频等信号使用IIR滤波器时都首先考虑贝塞尔，保证相位延迟一致

#### 巴特沃斯滤波器
巴特沃斯逼近目标为在整个通带和阻带内，幅频响应都尽可能平坦，因此设计出来的巴特沃斯滤波器是一种具有平坦通带和单调递减的阻带特性的滤波器。
它的幅频响应平方函数是：|H(ω)|² = 1 / (1 + (ω/ω_c)^(2N))，这是一个单调函数，因此没有纹波。
巴特沃斯滤波器的优点是通带内平坦，过渡带平滑，但缺点是阻带衰减较慢，过渡带比较长

#### 切比雪夫滤波器
在讨论FIR的特性时已经介绍过波纹和过度带之间的定性关系，因此切比雪夫滤波器在通带或阻带内允许一定的波动量 ΔKp​，从而在阻带内获得更快的衰减，过渡带更短。
切比雪夫I型滤波器的幅频响应平方函数为：|H(ω)|² = 1 / (1 + ε² * C_N²(ω/ω_c))
ε 是决定通带波纹大小的参数。C_N(x) 是 N阶切比雪夫多项式。

#### 稳定性
上面说到FIR滤波器系统函数形式为卷积和，因此其极点都为0，所以FIR滤波器是稳定的。而IIR滤波器系统函数形式为有理函数，因此其极点可能位于单位圆外，导致不稳定。
因此，设计IIR滤波器时，需要确保分母多项式的根位于单位圆内，以避免不稳定现象。于是，IIR滤波器大多都是从模拟滤波器通过模拟-数字转换器（如巴特沃斯、切比雪夫、贝塞尔等）来设计的，
并且更高阶稳定性要求更高，因此高阶IIR滤波器设计难度较大，因此高阶滤波器一般使用二阶节设计，二阶节设计稳定性高，且设计简单

#### 相位响应
相频特性是零点矢量相角的和与极点矢量相角的和之差，IIR的滤波器系统传递函数大多没有零点，因此相频特性主要由极点决定。
对于N阶低通巴特沃斯滤波器，其极点位于S左半平面一个以原点为圆心的圆上。这些极点关于实轴对称，并且在圆周上均匀分布。
均匀分布的极点使得总相位 φ(ω) 相对说更是一条平滑弯曲的曲线。因此巴特沃斯滤波器的相频特性是IIR 滤波器中相位响应相对最线性的，
因此群延时也是IIR种最小的，因此巴特沃斯更适合对相位有要求的滤波器设计。(贝塞尔之外)

#### 幅频响应
巴特沃斯牺牲过渡带来换取通带平坦，切比雪夫牺牲通带平坦来换取阻带衰减，因此切比雪夫滤波器在同阶情况下，阻带衰减更高，过渡带更短
阶数越高，阻带衰减越快，过渡带越短，但相位响应越非线性，因此设计时需要根据需求选择合适的阶数
